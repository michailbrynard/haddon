# Haddon documentation

Start with the [project README](../README.md) for what Haddon is and a short quickstart.

| Document | Read it when |
|---|---|
| [quickstart.md](quickstart.md) | you want to go from an empty directory to a closed month over HTTP |
| [concepts.md](concepts.md) | you want the accounting model: entries, corrections, the period lock, statements, documents |
| [agent-context.md](agent-context.md) | you want a short block to paste into an agent's instructions before it starts |
| [using-from-an-agent.md](using-from-an-agent.md) | you want the contract an agent works under on one page: discovery, idempotency, corrections, locked periods, errors, paging |
| [agent-guide.md](agent-guide.md) | you are connecting an LLM agent: tools, error handling, workflows, guardrails |
| [api.md](api.md) | you need the API conventions and route list (the full schema is at `/openapi.json`) |
| [reviewer-ui.md](reviewer-ui.md) | you want to run or understand the web interface |
| [hledger.md](hledger.md) | you are importing or exporting hledger journals, or running the oracle |
| [operations.md](operations.md) | you are deploying it: configuration, adding books, backups, restore drills |
| [architecture.md](architecture.md) | you are changing the code: the core, the extensions and the rules between them |
| [comparison.md](comparison.md) | you are choosing between Haddon, hledger, Beancount, Ledger and GnuCash |
| [design/](design/README.md) | you want to know why something is the way it is |
